# Setup Lab Environment

The lab environment is being prepared automatically. This includes:

1. Creating intentional misconfigurations for troubleshooting practice
2. Setting up users and groups
3. Preparing storage devices
4. Installing required packages

## Your Scripts

Three scripts are available in `/root/`:

- `setup_lab.sh` - Creates the exam environment (runs automatically)
- `validate_lab.sh` - Check your solutions
- `reset_lab.sh` - Reset environment to start over
